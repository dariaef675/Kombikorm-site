# Староюрьевский комбикормовый завод

Сайт ООО «Староюрьевский комбикормовый завод» (СККЗ) — производителя полнорационных комбикормов для сельскохозяйственной птицы, КРС и МРС, свиней, кроликов и рыбы. Собственное производство в Тамбовской области, работаем с 2014 года.

**Сайт:** https://kombikorm-tambov.ru

## Продукция

- комбикорма для птицы, свиней, КРС и МРС, кроликов, рыбы
- соответствие ГОСТ, рецептуры при поддержке ВНИИКП
- опт от 2 тонн и розница, доставка по всей России

Актуальный каталог и цены — на [сайте](https://kombikorm-tambov.ru).
